# 🚀 EssentiaAI — Summarize Smarter

EssentiaAI is a powerful, AI-driven Chrome extension that **summarizes long articles and blog posts** into concise insights — all in a single click. Powered by Google's Gemini API, it helps you focus on **what matters** by delivering brief, detailed, or bullet-style summaries, straight from your browser.

---

## ✨ Features

- 🧠 **AI-Powered Summarization** — Uses Gemini 1.5 Flash model to generate high-quality summaries.
- 📰 **Works on Any Webpage** — Extracts article content from blogs, news, or reading sites.
- 🎯 **Multiple Summary Modes**:
  - Brief Summary (3–4 lines)
  - Detailed Summary (Paragraph)
  - Bullet Points (5–7 concise points)
- 🌙 **Light/Dark Mode Toggle** — Seamless UI switch with theme memory.
- 📋 **One-Click Copy** — Copy the result with a single click.

---

## 🔧 How It Works

1. Click the extension icon in your Chrome toolbar.
2. Choose your preferred summary type.
3. Hit the **"Summarize"** button.
4. Sit back as EssentiaAI fetches content, talks to Gemini, and gives you instant insights.


## 🔑 Requirements

- A [Gemini API Key](https://makersuite.google.com/app/apikey)
- Chrome browser

---

## 🛠 Setup (For Developers)

1. Clone or download this repo.
2. Open Chrome and go to `chrome://extensions/`
3. Enable **Developer Mode**
4. Click **Load Unpacked** and select the project folder
5. Click the extension icon, set your Gemini API key, and start summarizing
